**Made for Kids:** do **not** opt into the Kids category. It brings extra requirements, and the game is not designed specifically for children under 11.

## 3. Export compliance (encryption)

* The app contains **no encryption**. There is no networking, no HTTPS, no CryptoKit or CommonCrypto, and no custom cryptography. Only OS-provided services are used.
* The project sets `ITSAppUsesNonExemptEncryption = NO` (verified in the built `Info.plist`), so App Store Connect will not ask the encryption question for each build.
* No export documentation (ERN/CCATS) and no French encryption declaration are needed.
* If a future version adds networking or cryptography, review this answer again.
